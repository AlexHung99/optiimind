MADE FOR YOUR EVERYDAY

一個對話，
接住你的工作。

把文字、圖片和 PDF 放進同一個聊天畫面。需要回頭找資料時，從左側紀錄接著聊。

01 /

文字、圖片與 PDF

按輸入框的 ＋ 選檔，或直接拖入聊天區。文字型 PDF 擷取內容；掃描頁可選頁交給圖片模型辨識。

02 /

截圖後立即提問

按輸入框旁的「截圖」，或用 Ctrl+Shift+S 框選畫面。圖片會先顯示在輸入框，確認後再傳送。

03 /

找回每一次對話

對話以第一次聊天的日期時間命名。左側可搜尋標題、提問、回覆與附件；點選結果會跳到命中的訊息。

04 /

選模型，也選運算裝置

在設定下載 Ollama 模型，分別選擇文字與圖片模型及 CPU/GPU。底部顯示 CPU、RAM、GPU 和 VRAM 使用情況。

05 /

切換到本機 Agent

在左側切到 Agent，選擇工作資料夾並輸入目標。Agent 可讀取 PDF 文字層、Excel、Word 和文字檔；編輯 Excel、Word 或文字時先預覽變更、確認後另存新檔，保留原件。

06 /

常駐與自動更新

關閉視窗會收至系統匣。啟動時檢查更新，執行中定期重試；離線仍可使用舊版，恢復連線後再更新。

GOOD TO KNOW

使用之前，先了解。

語音設計與聲音複製可以直接用嗎？

Windows 本機語音可在設定啟用自動朗讀。未達 NVIDIA 單卡 12 GB 顯存建議配置或無法偵測硬體時，程式會隱藏 Breeze 與服務參數。符合硬體條件後，Breeze 的 Voice Design / Clone 是官方 API 串接，需要自行提供已啟動的 Linux CUDA 服務；本程式不包含 Breeze 模型。其官方推論程式的音訊 tokenizer 以阿里巴巴 Qwen3-TTS 為基礎；是否自行架設由使用者決定。官方建議至少 12 GB 顯存，其權重與自架產出限研究及非商業用途。請參閱 Breeze 模型說明。

更新會清除我的設定或模型嗎？

不會。更新只替換程式包內檔案，設定、語音輸出與 Ollama 模型存放於程式資料夾之外。更新前會備份舊程式；偵測到本機程式修改會暫停套用。每次啟動會自動檢查 R2，離線時仍可使用現有版本；設定內也可按「立即檢查更新」。

PDF 可以讀哪些內容？

PDF 可拖入聊天框或用 ＋ 選檔；文字直接擷取，掃描檔第一頁會依大小縮小並壓縮，再交給圖片模型辨識，也可自行選頁。每份上限 100 MB；最多擷取 200 頁／60,000 字，送出時再依模型 Context 截取並清楚標示部分內容。未提供整份掃描文件自動 OCR，密碼保護文件請先解鎖。

聊天會自動存檔嗎？

對話自動存在本機，左側搜尋可查標題、提問、回覆與附件名稱，點選結果會捲到第一則命中訊息；按右鍵可重新命名或刪除。初始標題是第一次對話的日期時間。新送出的圖片可點擊放大查看，PDF 可雙擊交給 Windows 預設閱讀器開啟；附件副本只保存在本機，刪除對話時一併移除。舊紀錄若只保存縮圖仍可查看縮圖，缺少原檔的 PDF 需重新附加。重新分析時請再附加檔案。

為什麼 Llama 3.2 Vision 使用相容版本？

此版本為已驗證的 mllama 路徑保留 Ollama 0.24.0 相容服務，CPU 與 Vulkan GPU 使用獨立本機連接埠；其他模型使用一般 Ollama。GPU 可分層卸載，並不保證所有模型都能放入顯存。
