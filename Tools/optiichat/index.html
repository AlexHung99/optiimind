  • Windows 10 / 11，64 位元。

安裝包已內含 Python。首次啟動缺少相容執行檔時會下載官方 Ollama 0.24.0 ZIP（約 2.1 GB）。若完全沒有模型，再下載預設 llama3.2-vision（約 7.8 GB）。硬體需求依選擇的模型而異，CPU 推論可能需要數分鐘。
GOOD TO KNOW

使用之前，先了解。

語音設計與聲音複製可以直接用嗎？

Windows 本機朗讀可直接使用。未達 NVIDIA 單卡 12 GB 顯存建議配置或無法偵測硬體時，程式會隱藏 Breeze 與服務參數。符合硬體條件後，Breeze 的 Voice Design / Clone 是官方 API 串接，需要自行提供已啟動的 Linux CUDA 服務；本程式不包含 Breeze 模型。官方建議至少 12 GB 顯存，其權重與自架產出限研究及非商業用途。請參閱 Breeze 模型說明。

更新會清除我的設定或模型嗎？

不會。更新只替換程式包內檔案，設定、語音輸出與 Ollama 模型存放於程式資料夾之外。更新前會備份舊程式；偵測到本機程式修改會暫停套用。每次啟動會自動檢查 R2，離線時仍可使用現有版本；設定內也可按「立即檢查更新」。

PDF 可以讀哪些內容？

PDF 可拖入聊天框或用 ＋ 選檔；文字直接擷取，掃描檔第一頁會依大小縮小並壓縮，再交給圖片模型辨識，也可自行選頁。每份上限 100 MB；最多擷取 200 頁／60,000 字，送出時再依模型 Context 截取並清楚標示部分內容。未提供整份掃描文件自動 OCR，密碼保護文件請先解鎖。

聊天會自動存檔嗎？

對話自動存在本機，可從左側歷史清單開啟及改名；初始標題是第一次對話的日期時間。新送出的圖片會保存小尺寸預覽圖，PDF 顯示檔案圖示；舊紀錄若沒有縮圖則顯示圖片圖示。重新分析時請再附加原圖。

為什麼 Llama 3.2 Vision 使用相容版本？

此版本為已驗證的 mllama 路徑保留 Ollama 0.24.0 相容服務，CPU 與 Vulkan GPU 使用獨立本機連接埠；其他模型使用一般 Ollama。GPU 可分層卸載，並不保證所有模型都能放入顯存。
