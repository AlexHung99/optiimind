01 /

本機文字與圖片聊天

分別指定文字與圖片模型。附上圖片後自動分流，也能手動切換；回覆逐段顯示，隨時可停止。

02 /

框一下，就能問

Ctrl + Shift + S 框選畫面，放開即附加到對話。輸入的草稿會保留，按下傳送才交給模型。

03 /

聽見你的回答

Windows 本機語音可直接朗讀與匯出 WAV。符合顯存條件時，另提供 Breeze-TTS-2 Voice Design / Clone 服務串接。

04 /

運算方式自己決定

聊天模型可分別選 CPU 或 GPU，調整上下文、輸出長度與 GPU 層數。即時查看整機資源使用率。

05 /

適合每一個工作時段

亮色、暗色或跟隨 Windows。關閉視窗可收至系統匣，不打斷目前工作；重開會喚回同一個視窗。

06 /

更新，留到下次啟動

每天自動檢查一次新版、下載並驗證。下次開啟才套用，保留設定與模型，不在聊天途中重啟。

不包含模型權重 · 不是獨立 EXE 安裝包

開始前的準備

  • Windows 10 / 11，64 位元。
  • 先安裝 Python 3.11+ 與 Ollama for Windows。
  • 解壓縮至可寫入的資料夾，雙擊 Install-OptiiChat.cmd。
  • 完成後雙擊桌面「OptiiChat」捷徑啟動，也可使用 Start-OptiiChat.cmd。
第一次使用需要下載。
安裝腳本建立 Python 環境，缺少相容執行檔時會下載官方 Ollama 0.24.0 ZIP（約 2.1 GB）。若完全沒有模型，再下載預設 llama3.2-vision（約 7.8 GB）。硬體需求依選擇的模型而異，CPU 推論可能需要數分鐘。
GOOD TO KNOW

使用之前，先了解。

語音設計與聲音複製可以直接用嗎？

Windows 本機朗讀可直接使用。未達 NVIDIA 單卡 12 GB 顯存建議配置或無法偵測硬體時，程式會隱藏 Breeze 與服務參數。符合硬體條件後，Breeze 的 Voice Design / Clone 是官方 API 串接，需要自行提供已啟動的 Linux CUDA 服務；本程式不包含 Breeze 模型。官方建議至少 12 GB 顯存，其權重與自架產出限研究及非商業用途。請參閱 Breeze 模型說明。

更新會清除我的設定或模型嗎？

不會。更新只替換程式包內檔案，設定、語音輸出與 Ollama 模型存放於程式資料夾之外。更新前會備份舊程式；偵測到本機程式修改會暫停套用。可在設定關閉自動檢查，或按「立即檢查更新」。

聊天會自動存檔嗎？

目前聊天只保留在記憶體，真正結束程式後不保留。關閉視窗收至系統匣時仍會保留；更新不會強制結束程式。需要的回答可先複製。

為什麼 Llama 3.2 Vision 使用相容版本？

此版本為已驗證的 mllama 路徑保留 Ollama 0.24.0 相容服務，CPU 與 Vulkan GPU 使用獨立本機連接埠；其他模型使用一般 Ollama。GPU 可分層卸載，並不保證所有模型都能放入顯存。
