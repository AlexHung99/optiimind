🚗 停車模擬器 — 軌跡計算公式說明

本頁說明模擬器計算車輛軌跡所用的數學模型與公式。所有長度單位為公尺（m）、角度為弧度（文中標示度數者已換算）。

1. 座標系與符號約定

  • 世界座標：x 沿車道方向（畫面向右為正）、y 垂直車道（畫面向下為正）。停車格開口中心為原點。
  • 車輛姿態（pose）以後軸中心為參考點：位置 (x, y) 與車頭朝向角 θ。
  • g = 檔位方向：前進 g = +1，倒車 g = −1。
  • L = 軸距、δ = 前輪轉向角、R = 迴轉半徑、s = 沿路徑累計行駛距離。

2. 單車模型（Bicycle Model）

四輪車以等效兩輪（單車）模型近似：後輪固定、前輪轉向。低速無側滑時，車輛繞著「後軸延長線與前輪軸延長線的交點」（瞬時迴轉中心）旋轉。

tan δ = L / R 轉向角與迴轉半徑的關係（半徑量至後軸中心）。由使用者輸入的最小迴轉半徑 Rmin 反推最大轉向角：δmax = atan(L / Rmin)
κ = tan δ / L = 1 / R κ 為路徑曲率（curvature），方向盤打越多曲率越大。

車輛運動微分方程（以行駛距離 s 為參數，與速度無關）：

dθ/ds = g · κ
dx/ds = g · cos θ
dy/ds = g · sin θ 倒車（g = −1）時位置沿車頭反方向移動、旋轉方向也反向。這組方程是全部軌跡計算的基礎。
前輪轉向的三輪車（前2後1）：瞬時迴轉中心同樣位於後輪軸延長線上，上述方程完全相同——車身軌跡與四輪車一致，僅輪跡（各車輪掃過的路線）不同。

3. 垂直／斜角入庫 — 三段幾何解

路徑規劃為三段：車道直線 → 定曲率圓弧 → 車格軸線直線。已知條件：

  • 進場直線在車道遠側，橫向位置 ydrive = −rowSide · (車道寬/2 − 車寬/2 − 0.4)
  • 車格軸線單位向量 a，斜角車位的傾斜方向依「入庫方式 × 行駛方向」決定：leanDir = g · laneDir，使圓弧掃角最小（對應真實斜角停車場的排列方向）。
  • 終點後軸位置 Pf：由車格深處往回推——前進入庫扣（前懸 + 軸距）、倒車入庫扣（後懸）。

3.1 圓弧段

圓弧半徑取 R = Rmin（方向盤打滿），圓心 C 位於車輛左法線方向：

C = P + N(θ) · R · σ N(θ) = (−sin θ, cos θ) 為朝向的左法線；σ = ±1 為轉向側（σ = g · sign(Δθ)，Δθ 為起訖朝向差的主值）。

圓弧上取樣（起始朝向 θ₀、走過弧長 s）：

θ(s) = θ₀ + g · σ · s / R ， P(s) = C − N(θ) · R · σ

3.2 求圓弧起點（相切條件）

圓弧須同時與車道直線（起點）及車格軸線（終點）相切。圓心縱座標由車道相切決定：

Cy = ydrive + Ny · R · σ

弧末端點 Pa（朝向已轉到終向 θf）必須落在通過 Pf 的車格軸線上：

Pa,y = Cy − ny · R · σ ， Pa,x = Pf,x + (Pa,y − Pf,y) · ax / ay n = N(θ_f) 為終向左法線。由此反推圓弧起點 x₀ = P_a,x + n_x·R·σ，即「該在車道上哪個位置開始打方向盤」。

3.3 格內直線段

d = (Pf − Pa) · a 沿車格軸線的剩餘直線距離。若 d < 0 表示單一圓弧會越過停止點（迴轉半徑相對車道／車格過大），顯示需多段修正的警告。

4. 平行停車 — 速率受限轉向的 S 曲線

「方向盤不能瞬間打到底」以曲率對行駛距離的變化率限制建模：κ 隨 s 線性變化（近似緩和曲線 clothoid / Euler spiral）。倒車入庫的曲率剖面為反對稱五段：

κ(s) = ⎧ +k·s/dR （0 ≤ s < dR，打盤）
　　　⎪ +k （保持 L 米）
　　　⎪ +k → −k 線性（2dR 米，反打）
　　　⎪ −k （保持 L 米）
　　　⎩ −k → 0 線性（dR 米，回正） d_R = 1.5 m（打滿一圈方向盤所需行駛距離），k ≤ 1/R_min。剖面反對稱 ⇒ 淨朝向變化 Δθ = 0，倒車結束時車身自動回正。

軌跡由第 2 節微分方程以 Δs = 0.02 m 數值積分（中點法）求得。橫向位移目標：

Δytarget = yfinal − ydrive y_final 為路邊車格中心線、y_drive 為起始行駛線（貼近停放車列 0.4 m）。

因 Δy 對保持段長度 L、打盤距離 dR 與峰值曲率 k 皆單調，以二分法求解，且優先保持方向盤打滿（切深再反向，與真實駕駛一致）：

  • 橫移量大 → 固定 k = 1/Rmin（打滿），二分保持段 L，限制中途擺角 k·(dR+L) ≤ 50°（保證單調性與真實性）；
  • 橫移量小 → 仍保持打滿，縮短打盤距離 dR（二分 dR ∈ [0.3, 1.5]）——果斷切深、立即反打，而非淺打長繞；
  • 橫移量極小 → dR = 0.3 仍過量時才降低 k。

解出後將整條 S 曲線沿 x 平移，使倒車終點落在「距後車 0.3 m」的深處，再前進置中（真實駕駛的先深倒、後拉正技巧）。

5. 碰撞偵測 — 分離軸定理（SAT）

自車與前後鄰格障礙皆為矩形（OBB）。鄰格以「整格佔滿」模擬（障礙涵蓋整個鄰格：全格寬、內緣貼齊格線）——因為無法控制鄰車實際停放位置，一律以最壞情況測試。兩凸多邊形不相交 ⇔ 存在一條分離軸使兩者投影區間不重疊；候選軸取兩矩形各邊的法線（共 4 條不重複方向）：

對每條軸 u：若 max(projA) < min(projB) 或 max(projB) < min(projA) ⇒ 不相交 proj(p) = p · u。全路徑以 0.12 m 間隔取樣做此檢查，找出最早撞擊點。

6. 車位過短時的多段前後修正

單次 S 曲線會擦撞鄰車時，優先嘗試駕駛實務的「深切＋回正」二段式（僅 1 次換檔）：

倒切超打：後軸倒車切入深度 = yfinal + R(1 − cos φ₁)，φ₁ ≤ acos(1 − 車位餘寬/R) 利用車位寬度大於車寬的餘裕，倒車「超打」越過停放線；再以一段方向盤打滿的前進圓弧（半徑 R、掃角 φ₁）收回，終點恰好對齊停放線。φ₁ 由大到小搜尋，取第一個不與前後車碰撞的解；前進弧所需縱向空間 R·sin φ₁ 受前車限制，車位太短時無解，才進入下述多段修正。

二段式無解時，改用逐步數值模擬（rollout）產生多段路徑，模仿真實駕駛要領：

階段行為停止條件
倒車接近直退到車尾越過前車 → 朝路緣打盤至擺角 φswing → 反打回正（回正過程仍在倒車、持續獲得橫移）距鄰車 0.05 m、後軸到達深度下限、或已對齊
前進拉直方向盤朝路緣，把車身轉回與路平行距鄰車 0.05 m、超出前界、或走滿 3.5 m
置中對齊後前後直線移動至整車進格停妥判定

關鍵公式與參數：

φswing = clamp( atan(0.9 · |ey|), 0.12, 0.5 ) 目標擺角隨剩餘橫向誤差 e_y 縮小；打盤最多只用剩餘倒車跑道的一半，保留空間回正。
停妥判定：|φ| < 0.05 rad（≈2.9°） 且 |ey| < 0.15 m 且 整車位於前後車之間 φ 為車身與車道的夾角。
換檔時原地打盤：κ(換檔後第一步) = κcmd 換檔停止的瞬間，方向盤直接原地切到新目標角（真實駕駛的挪車要領），短跑道不浪費在轉方向盤上；行進間打盤仍受速率限制（全鎖約需 0.35 m 行程）。此作法可大幅減少前後修正次數。

每段移動記錄為姿態表格段，播放時依序重現；64 段內無法停妥則顯示「車位過短」警告並保留嘗試過程。

6.5 停妥後駛出（出庫軌跡）

低速無側滑的車輛運動具有時間可逆性：同一條路徑反向行駛（檔位反向 g → −g），每一點所需的方向盤角完全相同。因此：

出庫路徑 = 入庫路徑（去除進場直線）之倒序遍歷 ＋ 駛離直線 倒序段取樣：pose(s) = pose_入庫(ℓ − s)，檔位取負。入庫無碰撞 ⇒ 出庫必無碰撞。窄位的多段修正入庫，出庫時亦以相同的多段方式倒序挪出（先倒退貼近後車、再前進擺出），符合實際駕駛行為。

7. 車輪位置與方向盤顯示

前輪：(L, ±T/2)、後輪：(0, ±T/2)（三輪車後輪為 (0, 0)） T = 輪距；座標在車身坐標系（原點 = 後軸中心，x 朝車頭）。
方向盤顯示角 δ = atan( L · κ(s) ) HUD 與前輪動畫角度直接由當前路徑曲率換算，倒車段亦同。
