會勘案件：從回函到核准函

一次會勘要等十幾個局處回函。過去得一份份開來看、把意見手動抄進會勘紀錄， 再照著會勘紀錄重打一次核准函 —— 同一段文字抄兩遍，錯字就是這樣來的。

依地段地號分案

從主旨抓出「○○段○○地號」判斷同一案件，自動建立案件資料夾並把回函移進去。抓不到地號的留在原地，不亂猜。

產生會勘紀錄

把這一案各局處的「說明」逐條彙整成一張意見回復彙整表，附上來文日期與文號。原文照抄，不改寫。

產生核准函

依會勘紀錄轉成上行簽格式（主旨／說明／擬辦），只調整編號層級。查不到的欄位留下底線，等你填。

核准函一定從會勘紀錄產生，不是從原始掃描件

掃描件的辨識結果一定有要修的地方。會勘紀錄可以直接在程式裡編輯儲存， 核准函再從那份改好的檔案讀進來 —— 你的修正不會在下一步被丟掉。

它解決什麼問題

事務機掃出來的一堆檔名，沒人想手動開來看再改名。

預設完全離線

辨識模型隨程式安裝在本機，預設狀態下執行期不做任何連線，公文內容不會上傳。 雲端解析是另外的選項，要自己開、自己填金鑰。

繁體完整

採用字典達 18,708 字的辨識模型。上一代模型缺「範掃說別頁檢並屬議」等繁體專用字，公文會系統性缺字。

自動命名

抽出發文日期、發文字號、發文單位自動改名，民國年自動轉換。命名樣板可自訂。 套不上公文格式的檔案改用文件標題命名。可設輸出資料夾，改名後自動搬移歸檔。

文件瀏覽與分案

獨立分頁瀏覽整理過的資料夾，依發文日期排序，可搜尋機關、文號與日期。 能建立資料夾、拖曳搬移，也能依地段地號一次分好案件資料夾；重複執行不會產生重複資料夾。

去紅章與歪斜校正

濾除紅色印信而保留被壓住的黑字，並自動校正掃描歪斜——這兩項對辨識率的提升往往大於換模型。

收文戳記不進內文

收文章蓋在紙的下緣，常和本文最後一行重疊，辨識後會卡進句子中間。 程式在合併文字列之前就先把戳記整塊移除。

欄位用規則不用猜

字號與日期一碼都不能錯，因此採規則式抽取。抽不到會留下空值， 而不是生出一個看起來很合理的假資料——那種錯誤沒有人會發現。

對照檢視與就地編輯

雙擊開啟檢視視窗，可展開原始 PDF 逐頁對照。沒有對應 PDF 的檔案直接以全幅顯示， 並可按「編輯」直接修改內容後儲存。

雲端大語言模型解析選用

本機 OCR 之外，可改用 Claude、OpenAI 或 Gemini 解析。 金鑰以 Windows DPAPI 加密存放、不寫進設定檔，並可設每次與每月的成本上限， 送出前顯示預估花費。啟用後文件內容會送到該服務。

自動更新

安裝版會在背景取得新版並於下次啟動時套用，不會在你辨識到一半時強制重啟。 更新通常只有幾百 KB，不必重載整包。

接下來若是會勘案件，就到「瀏覽文件」分頁走 分案 → 會勘紀錄 → 核准函。 三顆按鈕依所在位置自動開關，走到哪一步就只有那一步能按，不會做錯順序。

1.4 這一版新增

主要圍繞在會勘案件的整段流程。

  • 依地段地號分案：從主旨抓地號判斷同案件，自動建案件資料夾並歸檔。
  • 會勘紀錄彙整：把各局處回函的說明逐條收成一張表，自動比對是哪個局處的意見。
  • 核准函草稿：由會勘紀錄轉成上行簽格式，意見原文照抄。
  • 會勘紀錄可編輯儲存：辨識有誤直接在程式裡改，改完再產生核准函。
  • 收文戳記移除：戳記不再卡進本文句子中間。
  • 會勘名稱與時間：從會勘通知單補上這兩個欄位，不再留空。
  • 設定介面：辨識方式、命名樣板、資料夾、雲端金鑰與成本上限集中在一處。

本程式目前尚未購買程式碼簽章憑證，Windows 可能顯示「不受信任的發行者」。 點選「其他資訊」→「仍要執行」即可。若不放心，請改用免安裝版並自行檢查檔案。

適用範圍

欄位規則依《文書處理手冊》的制式格式撰寫，適用於橫式公文。 直排公文（民國 94 年以前）與非制式文件（會議紀錄、簽呈變體）需要另行調整。

會勘功能目前對應桃園市政府

「哪一份回函屬於哪個局處」是靠一份固定的機關對照表判斷的， 目前收錄桃園市政府所屬 14 個單位及其常見簡稱（建管處、經發局、養工處…）。 其他縣市可以用，但局處要重新對照。分案、辨識、改名等其他功能不受這個限制。

產出的是草稿，不是可直接發文的公文

會勘紀錄與核准函都需要人工複核。抓不到的欄位（例如申請面積）會留下底線提示， 程式不會替你填一個看起來合理的數字。
