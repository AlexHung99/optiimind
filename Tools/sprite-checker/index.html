🎞️ Sprite Sheet 驗證工具

1. 載入圖片
點擊選擇圖片
或拖放 / Ctrl+V 貼上
尚未載入圖片
非透明背景的圖（純色/棋盤格）可先去背，再用自動偵測/自動內容切割。
2. 切割設定
自動內容：忽略多餘空白，依透明間隙逐列掃描、切出每格實際內容（適合間距/邊界不一的圖，各格可不同寬）。
3. 動畫範圍
左圖點格子＝設起始格；Shift+點＝設結束格
快速選整列（自動略過空白格）：
4. 播放控制
Space 播放/暫停，←→ 逐格
5. 預覽顯示
6. 對齊分析
載入圖片後顯示各格中心相對錨點的偏移量。
紅＝X 偏移、藍＝Y 偏移（像素）。理想動畫各格中心應貼近 0，偏移大代表中心不一致需修正。
7. 匯出 / 分享
匯出範圍＝目前動畫範圍。分享連結含所有參數（不含圖片；遠端圖可用 ?img= 帶入）。
